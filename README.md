# 📊 Dashboard de Vendas em Excel

## 🎯 Objetivo

O objetivo deste projeto é criar um **dashboard de vendas interativo e visualmente organizado** utilizando o Microsoft Excel. A proposta central é transformar uma base de dados bruta em **informações claras e acionáveis**, auxiliando na **análise de desempenho comercial** e facilitando a **tomada de decisões baseadas em dados**.

## 🛠️ Ferramentas Utilizadas

- **Microsoft Excel (Desktop e Online)**
- Tabelas Dinâmicas
- Segmentações de Dados (Slicers)
- Gráficos de Colunas, Pizza e Indicadores
- Fórmulas básicas (SOMA, MÉDIA, etc.)
- Limpeza e organização de dados

## 🔍 Análises Realizadas

### 1. Plano Mais Popular entre os Assinantes

Através da contagem do número de assinantes por tipo de plano, foi possível identificar **qual é o plano de assinatura mais escolhido pelos clientes**. Esse dado ajuda a empresa a entender a preferência do público e a planejar estratégias promocionais para os demais planos.

- **Visualização usada:** Gráfico de colunas com destaque para o plano com maior número de assinantes.

---

### 2. Clientes com Renovação Automática

Analisamos a quantidade de clientes que ativaram a **renovação automática da assinatura**, o que indica **fidelização** e **potencial de receita recorrente**. Esse dado é essencial para medir o engajamento e a confiança dos usuários no serviço.

- **Visualização usada:** Gráfico de barras "Sim vs. Não" e indicador numérico com o total.

---

### 3. Tipo de Assinatura que Gera Mais Receita

Avaliamos o **faturamento total por tipo de assinatura**, revelando qual modelo contribui mais significativamente para a receita da empresa. Esse dado é útil para direcionar investimentos em marketing, suporte e expansão de planos mais lucrativos.

- **Visualização usada:** Gráfico de colunas com soma da receita por tipo de assinatura.

---

## ✅ Conclusão

Este projeto demonstra como **dados brutos podem ser transformados em insights poderosos** com o uso de ferramentas acessíveis como o Excel. Com análises visuais simples e objetivas, é possível identificar padrões, comportamentos dos clientes e oportunidades de melhoria. O dashboard final proporciona uma **visão clara e rápida do desempenho de vendas**, contribuindo diretamente para estratégias comerciais mais eficientes.
